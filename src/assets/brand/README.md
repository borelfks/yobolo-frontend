# Logo YIBOLO

Redessiné en SVG d'après la maquette du client (`NOUVEAU DESIGN YIBOLO.docx`).

| Fichier | Usage |
|---|---|
| `yibolo-icon.svg` | Icône seule (favicon, icônes d'application) |
| `yibolo-icon-white.svg` | Icône sur fond bleu nuit |
| `yibolo-logo.svg` | Icône + « YIBOLO » + devise |
| `yibolo-logo-white.svg` | Logo complet sur fond bleu nuit |

Dans l'interface, le logo est dessiné par le composant `Logo` (`src/shared/components/ui/Logo.tsx`), mêmes formes et mêmes couleurs.
Les icônes PNG de `public/icons/` sont générées à partir de `yibolo-icon.svg`.
